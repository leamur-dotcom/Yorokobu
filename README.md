# Yorokobu Cerámica 🏺

Sitio web de Yorokobu Cerámica — tienda artesanal en Barcelona.

## Deploy en Vercel

1. Subí esta carpeta a un repositorio de GitHub
2. Entrá a [vercel.com](https://vercel.com) y conectá tu cuenta de GitHub
3. Importá el repositorio → Vercel lo detecta automáticamente
4. Click en **Deploy** → listo ✅

## Estructura

```
yorokobu-web/
├── public/
│   └── index.html    ← toda la web (imágenes embebidas)
├── vercel.json       ← configuración de Vercel
└── README.md
```

## Personalizar

- **Precios**: buscá `desde XX€` en `index.html`
- **WhatsApp**: reemplazá `34000000000` con tu número real
- **Instagram**: ya apunta a `@yorokobu.ceramica`
- **Colores**: variables CSS en `:root` al inicio del `<style>`
